# وب‌سایت استودیوی معماری فارسی

بازسازی مستقل و فارسیِ زبان بصری سایت معماری مرجع ارائه‌شده در ویدیو.

## سند مرجع

مشخصات کامل طراحی و پیاده‌سازی در فایل محلی architecture-site-spec-fa.md قرار دارد و مبنای تصمیم‌های این پروژه است.

## Stack

Next.js App Router / TypeScript / Tailwind CSS / GSAP / ScrollTrigger / GSAP Flip / Lenis / Framer Motion / next/image

## وضعیت پایه

این Commit اسکلت اولیه پروژه را ایجاد می‌کند: Home، Projects، Project Detail، Studio، Journal، Contact، Header، Mobile Menu، Footer، Smooth Scroll، پایه Animation System و داده مرکزی پروژه‌ها.

SVGهای فعلی فقط Placeholder هستند و در مرحله بعد با تصاویر واقعی معماری جایگزین می‌شوند.

## اصل طراحی

هدف، بازسازی تجربه Editorial / Cinematic مرجع است؛ مخصوصاً Shared Element Transition، Image Movement، Typography Reveal، Stagger و فضای سفید.
